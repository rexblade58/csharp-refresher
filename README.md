# C# Refresher

Console application collecting worked examples of core C# language concepts. Built as a structured refresher rather than a single-purpose program.

## Concepts Covered

| File | Topic |
| --- | --- |
| `Concepts/VariableExample.cs` | Variable declaration and scope |
| `Concepts/VariablesExample.cs` | Value and reference semantics |
| `Concepts/ArrayExample.cs` | Arrays and iteration |
| `Concepts/ControlStatements.cs` | Conditionals and loops |
| `Concepts/MethodsExample.cs` | Method definition, parameters, returns |
| `Concepts/EnumExample.cs` | Enumerations |
| `Concepts/MyClass.cs` | Classes, fields, and members |
| `Concepts/UserInputExample.cs` | Console input handling |

## Building

Open `ConsoleApp1.sln` in Visual Studio and build, or from the command line:

```bash
msbuild ConsoleApp1.sln
```

Entry point is `Program.cs`.
